# Ευρετήριο Οικοπέδων

Dashboard που, με διεύθυνση ή συντεταγμένες, εμφανίζει το ΚΑΕΚ και τα δημόσια στοιχεία του γεωτεμαχίου
(χρήση, εμβαδόν, οριζόντιες/κάθετες ιδιοκτησίες, ΟΤΑ, δασικός χάρτης, Natura, συντεταγμένες WGS84/ΕΓΣΑ87).

Πηγές: δημόσιες υπηρεσίες του Ελληνικού Κτηματολογίου (maps.ktimatologio.gr) και OpenStreetMap Nominatim.
Τα στοιχεία είναι ενδεικτικά και δεν υποκαθιστούν επίσημο απόσπασμα. Στοιχεία ιδιοκτητών δεν δημοσιεύονται.

## Ευκαιρίες Flip (`flip.html`)

Λίστα με όλες τις κατοικίες προς πώληση του [Intrum Marketplace](https://marketplace.intrum.gr/residential/sale), με εκτίμηση
κέρδους για αγορά → ανακαίνιση → μεταπώληση. Ο καθένας βάζει τα δικά του φίλτρα και ρυθμίσεις κόστους· αποθηκεύονται στον browser του
και μπορούν να εξαχθούν/φορτωθούν ως αρχείο.

Για κάθε ακίνητο υπολογίζει:

- **Τιμή πώλησης μετά την ανακαίνιση** = €/m² × εμβαδόν, με προτεραιότητα: δική σου τιμή για τον δήμο → για την περιοχή →
  μέση τιμή Indomio του δήμου/γειτονιάς για την Αττική (`data/market-prices.json`) → δείκτης Spitogatos της περιοχής
  (`data/arv-defaults.json`) διορθωμένος με τη σχετική θέση του δήμου μέσα στην περιοχή →
  αυτόματη εκτίμηση από τον διάμεσο €/m² των αγγελιών Intrum. Διορθώσεις για ισόγειο, υπόγειο, παλιό κτίριο, μέγεθος, όροφο χωρίς ασανσέρ.
- **Κόστος ανακαίνισης** ανάλογα με έτος κατασκευής, ενεργειακή κλάση και αν είναι ημιτελές (ελαφριά / μέτρια / πλήρης).
- **Κόστη** αγοράς, κράτησης, πώλησης και φόρου, **καθαρό κέρδος**, **ROI** και **μέγιστη τιμή προσφοράς** για τον στόχο ROI.

Κάθε ακίνητο ανοίγει απευθείας στο Ευρετήριο Οικοπέδων (`index.html?q=<διεύθυνση>`) για ΚΑΕΚ, όρους δόμησης και δασικά.

### Δεδομένα

`data/listings.json` παράγεται από το `scraper/scrape.js`: ανοίγει τις δημόσιες σελίδες του site με headless Chromium,
διαβάζει τη λίστα (50 ανά σελίδα) και μετά τη σελίδα κάθε ακινήτου που είναι νέο, άλλαξε τιμή ή έχει να ελεγχθεί 30 μέρες.
Κρατά ιστορικό τιμών και σημειώνει όσα αποσύρθηκαν.

Το GitHub Action `.github/workflows/scrape-intrum.yml` το τρέχει κάθε πρωί και κάνει commit τις αλλαγές.
Χειροκίνητα: Actions → «Ανανέωση αγγελιών Intrum» → Run workflow, ή τοπικά:

```bash
npm install --no-save playwright && npx playwright install chromium
node scraper/scrape.js --minutes 120 --concurrency 4
```

Οι υπολογισμοί είναι ενδεικτικοί, βασίζονται σε ζητούμενες τιμές και δεν υποκαθιστούν αυτοψία, εκτίμηση και νομικό/τεχνικό έλεγχο.
