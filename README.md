# Ευρετήριο Οικοπέδων

Dashboard που, με διεύθυνση ή συντεταγμένες, εμφανίζει το ΚΑΕΚ και τα δημόσια στοιχεία του γεωτεμαχίου
(χρήση, εμβαδόν, οριζόντιες/κάθετες ιδιοκτησίες, ΟΤΑ, δασικός χάρτης, Natura, συντεταγμένες WGS84/ΕΓΣΑ87).

Πηγές: δημόσιες υπηρεσίες του Ελληνικού Κτηματολογίου (maps.ktimatologio.gr) και OpenStreetMap Nominatim.
Τα στοιχεία είναι ενδεικτικά και δεν υποκαθιστούν επίσημο απόσπασμα. Στοιχεία ιδιοκτητών δεν δημοσιεύονται.
